# FORM · CMF 材料与配色工作台

公开试用版。此仓库保存构建后的网页，可直接由 GitHub Pages 托管。

## 开启试用网址

在仓库 Settings → Pages → Build and deployment 中，选择 Deploy from a branch，再选择 main 分支和 / (root)，保存。发布完成后，以 Pages 页面显示的 Visit site 网址为准。

## 试用流程

1. 首次打开会载入座椅示例，可先选择部件，调整颜色、材料和工艺。
2. 自有底图请从 VRED 输出同视角、同尺寸的 Beauty 图与 Material ID 图，转成 sRGB PNG/JPG 后导入。
3. 可按 ID 批量建部件，修整蒙版，复制方案，调整纹理、打孔、压纹与缝线，并导出 PNG、规格 CSV 和项目备份。

## 数据和使用范围

项目、素材和模板保存在当前浏览器中。该版本没有服务器上传或团队共享功能。
原 chatgpt.site 地址与此网址使用不同的浏览器存储；继续旧方案需在原站下载项目备份，再在此站打开备份。
清理浏览器数据可能丢失本地工作，请定期下载项目备份。

材料与工艺画面是二维示意，9 点网格用于近似贴合。真实光照、曲面材质和工艺可行性仍需 VRED 或实物样件验证。

本仓库仅包含网页程序和内置示例素材，不包含使用者保存在浏览器中的方案或上传的底图。
